# Prasanta Kumar Parida — Portfolio

Modern React + Vite portfolio built from the supplied resume.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages

1. Create a GitHub repository.
2. Copy this project into it.
3. Put your resume PDF at `public/Resume.pdf`.
4. If the repository is `username.github.io`, use `/` as the Vite base.
5. If it is a project repository such as `portfolio`, add `base: '/portfolio/'` to `vite.config.js`.
6. Deploy the generated `dist` folder with GitHub Pages or GitHub Actions.

## Personalization

Update the GitHub and LinkedIn URLs in `src/main.jsx` if needed.
